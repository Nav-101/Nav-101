Precision Mixed-Signal ADC Subsystem

Objective

Design a compact mixed-signal measurement board capable of stable, low-noise analogue acquisition alongside digital activity.

Architecture

  • ΔΣ ADC
  • Precision voltage reference
  • RC input filtering
  • SPI interface to MCU

Design Decisions

Analogue island partitioning, controlled return paths, reference integrity management, and 4-layer PCB with solid planes.
